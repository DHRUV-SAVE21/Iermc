# Motion direction

The presentation direction was informed by smart-city and traffic-interface work on Dribbble, particularly [Smart City Dashboard Interface by Fuselab Creative](https://dribbble.com/shots/26025012-Smart-City-Dashboard-Interface). Its city-scale coordination framing is relevant to the project.

The website uses original local SVG artwork rather than copied screenshots, downloaded videos, or third-party media. The aerial traffic scene contains animated vehicles, signals, a disruption marker, and alternative corridor overlays. It is a motion illustration, not a recorded video or live traffic camera.

The current presentation uses flat colours, direct product language, rectangular controls, and a short loading state when opening the command centre. The landing page opens directly. Decorative motion, opening sweeps, gradient effects, and unvalidated improvement headlines have been removed. The workspace retains clearly disclosed synthetic scenario outputs for demonstrating the planning flow.
